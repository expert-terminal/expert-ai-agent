# Expert AI Agent: quick start

1. Install **Expert AI** on Android, or open the Expert AI web app, and sign in.
2. Install and open **Expert AI Agent** on your Windows computer. Sign in with the same account.
3. In Expert AI, open **Agent** → **Your computers** and choose **Connect** beside this computer. If it is not listed, use the desktop app's QR code or pairing code.
4. Select the workspace the agent should work in. Enable the tools you need, such as Bash, before asking it to run commands.
5. Try: “List the files in this workspace,” or “Explain this project and suggest the next change.” Review file changes before using them.

The agent runs file and shell tools on the desktop inside the selected workspace. Programs such as FFmpeg can be used through Bash when installed on that computer. Keep the desktop app running while using Agent mode on your phone. Simple Chat remains a separate experience.
